# Remember

Use when Fraser shares a stable fact or preference ("remember that…", a project detail, how he likes
something done), or when you learn something clearly worth keeping.

## Workflow

1. Decide if it's durable (stable, reusable) or transient (only relevant right now). Store only
   durable things.
2. Write a concise, self-contained note to memory — what it is and how to apply it.
3. Confirm briefly what you saved.

## Guardrails

- Memory is for stable facts/preferences, not a transcript log. Keep it tight.
- Never store secrets or credentials in memory.
- If something changes, update the existing note instead of piling on duplicates.
